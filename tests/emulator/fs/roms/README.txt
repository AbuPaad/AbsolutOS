ROMs in this directory are fixtures for the Game Boy app. They ship in the
WebAssembly preload image (`--preload-file .../fs@/`), so every one of them has
to be licence-clear to redistribute. Never add a commercial ROM here.

Petris.gbc
  Petris, by bbbbbr. MIT licence (source and assets).
  https://github.com/bbbbbr/Petris  (branch release_1.1_gbdk2020, rom/Petris_web.gbc)
  Free homebrew puzzle game for the Game Boy Color. Bundled for the browser
  demo so a visitor can boot a real, playable game.
  Copyright (c) bbbbbr. Distributed under the MIT License.

dmg-acid2.gb
  dmg-acid2, by Matt Currie. MIT licence.
  https://github.com/mattcurrie/dmg-acid2
  PPU rendering test, not a game. Kept as the emulator's accuracy fixture.
