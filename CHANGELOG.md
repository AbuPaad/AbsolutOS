# Changelog

## 1.1

- **Over-the-air updates.** Settings → System Update checks the release feed and
  installs the new image into the spare OTA bank, then reboots.
- **Wolfram|Alpha check.** The AI app verifies a result against Wolfram|Alpha;
  the AppID is set in the web portal.
- **2D math in notes.** A subset-LaTeX → MathAST compiler lets the markdown
  renderer draw real math.
- **Sturdier HTTPS.** TLS sessions are serialised behind one memory budget.
- **Casio theme.** Apps move to the Casio look with a new Casio font asset.
- **Serial input bridge.** Drive the device from a PC over the serial console.
